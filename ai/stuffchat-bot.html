A coding helper for your servers.

While this page stays open, Stuff AI watches invited rooms and replies to /stuffai_hi and /stuffai your question.

Connect account and rooms

Create the separate Stuffchat account (example ID stuffai, display name Stuff AI). Add that ID to each server's allowed-users list, save admin settings, then paste its invite.

Invite links grant room access. Only add rooms where you intend the bot to read and reply. Links and room keys are held only in this tab's memory.

Start / stop

Not listening

Checks every 6 seconds. Keep this page and device awake; only one bot tab/device should listen per account.

Stuffchat mentions here are ordinary encrypted messages. The bot uses its own account ID as sender and ignores its own messages.

Setup steps

  1. Create/log into the separate Stuffchat account named stuffai; set display name to Stuff AI.
  2. In each server admin settings, add stuffai to allowed users.
  3. Copy each server invite link and paste it above.
  4. Load a model, then Start listening.

/stuffai_hi checks the bot. /stuffai explain this error: ... asks it a question.
